# 苍痕之森

一款直接运行于浏览器的横向卷轴 2D 狩猎动作游戏原型。玩家将操作携带太刀的猎人，穿越四片相互衔接的生态区域，依次挑战野猪王、人鱼兽、泥龙与最终首领斩龙。

当前版本为第一版可玩原型，已经包含完整地图、猎人移动与太刀连段、生命与体力、气刃系统、大型怪物 AI、区域生态以及首领战。

## 游戏特色

- 单页 HTML5 Canvas 游戏，无需安装框架或构建工具。
- 四个连续区域与随地形变化的可行走地面。
- 步行、奔跑、翻滚、无敌帧、体力消耗与恢复。
- 太刀基础连段、气刃连段、特殊纳刀、小居合与大居合。
- 无色、白刃、黄刃、红刃四级气刃等级和叠加伤害修正。
- 四只拥有独立外形、动作序列和攻击逻辑的大型怪物。
- 斩龙“刚刃研磨 · 聚合斩”首领机制，需要使用翻滚无敌帧规避。
- 猎人连续 15 秒未受伤后缓慢恢复生命；力尽后重返战场时保留怪物已损失的生命。

## 操作方式

| 按键 | 动作 |
| --- | --- |
| `A` / `D` 或方向键 | 左右移动与选择特殊纳刀朝向 |
| `Shift` + 移动 | 奔跑，持续消耗体力 |
| 双击 `A` / `D` | 向对应方向翻滚，消耗 25 点体力并获得短暂无敌帧 |
| `J` | 踏步斩；突刺后派生上捞；特殊纳刀中使用小居合 |
| `K` | 突刺；特殊纳刀中使用大居合 |
| `L` | 气刃斩及后续气刃连段 |
| `Ctrl` | 在允许派生的攻击后进入特殊纳刀 |
| `R` | 重置猎人位置与战斗状态 |
| `H` | 显示或隐藏界面 |

气刃大回旋、大居合命中后可以升刃，落空则会掉刃。刃等级十秒内没有再次提升时会自动下降一级。

## 大型怪物

1. **野猪王**：冲撞、撕咬、后踢。单次伤害较低，但攻击具有击倒能力。
2. **人鱼兽**：鳞潮碰撞、裂鳞爪击、潮尾拍击，拥有更大的攻击覆盖范围。
3. **泥龙**：撕咬、尾拍和泥潭喷吐。猎人进入泥潭后会持续损失体力。
4. **斩龙**：撕咬、爪击以及刚刃研磨后的聚合斩。聚合斩会长距离突进并造成致命伤害。

## 本地运行

可以直接打开 `index.html`，也可以在当前目录启动任意静态文件服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 项目结构

```text
.
├─ index.html                 # 游戏页面、状态机与 Canvas 渲染逻辑
├─ assets/                    # 场景、猎人和怪物图像素材
├─ .github/workflows/         # GitHub Pages 自动部署流程
├─ .nojekyll                  # 禁用 Jekyll 处理，原样发布静态资源
└─ README.md
```

## GitHub Pages 部署

仓库已经包含 Pages 工作流。将代码推送到 `main` 分支后，在仓库的 **Settings → Pages → Build and deployment** 中把 Source 设为 **GitHub Actions**，工作流会自动发布整个游戏目录。后续每次推送到 `main` 都会重新部署。
